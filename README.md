Pasar Lentera Senja — a complete, original spot the difference game. Three hand-drawn scenes (a lantern market stall, a cake & toy shop interior, a night-market alley) with 5, 7 and 9 fair differences; a named found-list, a hover magnifier, hints, hearts, streaks and stars, WebAudio sounds, and keyboard + mouse play. No network requests — everything is static files under game/.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in desktop Chrome.
